# MLInsight — Machine Learning Explorer

Website edukasi interaktif berbahasa Indonesia untuk topik **Introduction to Machine Learning**.

## Fitur
- Penjelasan konsep dasar dan tujuan Machine Learning.
- Ringkasan Supervised, Unsupervised, dan Reinforcement Learning.
- Penjelasan algoritma Linear Regression, Decision Tree, k-Nearest Neighbors, dan K-Means.
- Simulasi heuristik klasifikasi bunga Iris.
- Grafik sebaran data ilustratif.
- Contoh studi kasus keuangan, kesehatan, dan bisnis.
- Desain responsif, menu mobile, dan tombol tema.

## Menjalankan secara lokal
Buka `index.html` di browser. Tidak membutuhkan server atau instalasi library.

## Deploy ke GitHub Pages
1. Buat repository publik baru, misalnya `mlinsight-machine-learning`.
2. Upload `index.html`, `style.css`, `script.js`, dan `README.md` ke root repository.
3. Buka **Settings → Pages**.
4. Pada **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/(root)`, lalu klik **Save**.
6. Tunggu deployment selesai, lalu buka URL Pages yang ditampilkan GitHub.

## Catatan akademik
Website ini adalah media pembelajaran umum berdasarkan topik webinar “Introduction to Machine Learning”, bukan transkrip atau rangkuman terverifikasi dari keseluruhan webinar. Data grafik bersifat ilustratif. Prediksi bunga Iris menggunakan aturan sederhana di JavaScript dan **bukan model machine learning terlatih**. Gunakan transkrip, slide, atau sumber kuliah untuk melengkapi materi sesuai isi webinar yang sebenarnya.
